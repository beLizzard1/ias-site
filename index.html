Identity Acceptance Surfaces

Where does an identity stop being accepted?

Perturb an identity embedding at known amplitudes, then map where a real discriminator flips from accepting to rejecting it — along controlled geometric directions, not random noise. Built for INT8 / edge deployments, where the score surface hides plateaus, cliffs, and aliasing that aggregate FAR / FRR never show.

Each shell is an initial sample at known distances from the anchor identity, in the embedding metric — that first pass is run against the system under test. Per direction, those results show where a new test case is needed to pin down the acceptance threshold; across many directions that builds up the acceptance surface, which we compare to the ideal one.
